# Confidentialité

Comment ce site utilise les statistiques.

## Statistiques

Nous utilisons Cloudflare Web Analytics pour compter les pages vues. Il ne dépose aucun cookie, n'enregistre rien sur votre appareil et ne vous suit pas d'un site à l'autre. Il ne se charge qu'après votre accord.

## Vos données

Nous ne diffusons pas de publicité, ne vendons ni ne partageons vos données et ne créons aucun profil vous concernant. Votre choix est enregistré dans votre navigateur et ne quitte jamais votre appareil. Si vous effacez les données de ce site, la question vous sera reposée.

## Votre choix

Vous n'avez pas encore choisi. Les statistiques restent désactivées jusque-là.
