# Datenschutz

Wie diese Website Analytics nutzt.

## Analytics

Wir nutzen Cloudflare Web Analytics, um Seitenaufrufe zu zählen. Es setzt keine Cookies, speichert nichts auf Ihrem Gerät und trackt Sie nicht über Websites hinweg. Es wird nur geladen, wenn Sie zustimmen.

## Ihre Daten

Wir schalten keine Werbung, verkaufen oder teilen Ihre Daten nicht und erstellen kein Profil von Ihnen. Ihre Auswahl wird in Ihrem Browser gespeichert und verlässt Ihr Gerät nie. Wenn Sie die Daten dieser Website löschen, fragen wir erneut.

## Ihre Auswahl

Sie haben noch nicht gewählt. Analytics bleibt deaktiviert, bis Sie es tun.
