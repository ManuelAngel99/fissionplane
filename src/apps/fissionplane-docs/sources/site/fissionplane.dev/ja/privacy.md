# プライバシー

このサイトにおけるアクセス解析の利用方法。

## アクセス解析

ページビューの計測に Cloudflare Web Analytics を使用します。Cookie は使用せず、お使いのデバイスには何も保存せず、サイトをまたいで追跡することもありません。同意された場合にのみ読み込まれます。

## あなたのデータ

広告の配信、データの販売や共有、プロファイルの作成は行いません。選択内容はブラウザに保存され、デバイスの外に出ることはありません。このサイトのデータを消去すると、再度お尋ねします。

## あなたの選択

まだ選択されていません。選択するまでアクセス解析は無効のままです。
